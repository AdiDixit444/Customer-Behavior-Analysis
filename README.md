# 📊 Customer Behavior Analysis

## 📌 Project Overview

This project analyzes customer purchasing behavior to uncover actionable business insights using **Python**, **MySQL**, and **Power BI**. The workflow covers data cleaning, exploratory data analysis (EDA), SQL-based business analysis, and interactive dashboard creation to support data-driven decision-making.

The project demonstrates an end-to-end data analytics pipeline, from preparing raw data to presenting insights through an interactive dashboard.

---

## 🚀 Objectives

* Clean and preprocess customer sales data.
* Perform Exploratory Data Analysis (EDA) to understand customer behavior.
* Analyze sales data using advanced SQL queries.
* Create an interactive Power BI dashboard for business reporting.
* Generate insights to support strategic business decisions.

---

## 🛠️ Technologies Used

* **Python**
* **NumPy**
* **Pandas**
* **MySQL**
* **Power BI**

---

## 📂 Project Workflow

### 1. Data Preprocessing (Python)

* Imported and explored the dataset.
* Removed null and duplicate records.
* Renamed column names using **snake_case** notation.
* Performed data cleaning and formatting.
* Prepared the dataset for further analysis.

---

### 2. Exploratory Data Analysis (EDA)

Using **NumPy** and **Pandas**, the dataset was analyzed to identify:

* Customer purchasing patterns
* Sales trends
* Product performance
* Revenue distribution
* Category-wise analysis
* Key statistical summaries

---

### 3. SQL Analysis

Business insights were extracted using MySQL by leveraging:

* Joins
* Subqueries
* Window Functions
* Aggregate Functions
* Group By and Having Clauses
* Common analytical SQL techniques

Some business questions answered include:

* Top-performing products
* Highest revenue-generating categories
* Customer purchase behavior
* Sales trends over time
* Revenue contribution by different segments

---

### 4. Power BI Dashboard

The cleaned data and SQL insights were transformed into an interactive Power BI dashboard featuring:

* Sales Overview
* Revenue Analysis
* Customer Insights
* Product Performance
* Category-wise Sales
* Interactive Filters and Slicers
* KPI Cards
* Trend Visualizations

The dashboard enables stakeholders to quickly explore business performance and make informed decisions.
